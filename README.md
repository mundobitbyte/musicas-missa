# Músicas para a Missa

Protótipo atual do projeto Mundo bit Byte.

## Direção visual
- simples;
- elegante;
- funcional;
- preparado para repertório grande;
- repertório em lista compacta;
- pesquisa em destaque;
- filtros rápidos por momento;
- uso confortável em celular e desktop.

## Princípio central
A curadoria das músicas é feita pelo responsável pelo projeto.
O site apenas organiza, pesquisa, filtra e apresenta o repertório.

## Tecnologias
HTML + CSS + JavaScript + JSON.
